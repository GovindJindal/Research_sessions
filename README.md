# Evolve AI – Research Sessions 🧠🚀

This repository contains **research, practice, and experimental projects** developed as part of **Evolve AI Research Sessions**.  
It serves as a structured workspace for learning, exploring, and building applications in **Web Development, React, Node.js, and AI-related concepts**.

🔗 **Live Deployments:**  
- https://research-sessions-ecru.vercel.app/

---

## 📁 Repository Overview

Each folder represents a **separate research session or mini-project**, created while exploring different technologies and problem-solving approaches.
